PaddleMatch

Final project, web application

A web app that helps beginner and recreational pickleball players choose a paddle and find people to play with.

  • Recommends paddles from skill level, playing style and budget, using a scoring rule (40 points for skill fit, 35 for style, 25 for budget).
  • Players register, send match requests, and opponents accept or decline. Recorded results update wins, losses and points on a leaderboard.
  • Express API on PostgreSQL with scrypt-hashed passwords, hashed session tokens, parameterized queries, and a database transaction when a result is recorded.
  • Front end deployed on GitHub Pages with GitHub Actions, API on Render, database on Neon.
  • Documented my AI-assistant use in the repository, including what I changed and where it was wrong.
  • React

  • Node.js

  • PostgreSQL
  • GitHub Actions

Price Watch PH, e-commerce price monitoring extension

Undergraduate thesis, group of four

A Chrome and Edge extension (Manifest V3) that tracks product prices on Shopee and Lazada Philippines and alerts the user when a price reaches their target. It runs in the browser and keeps data on the user's device, so it needs no external server.

  • Four rule-based steps: URL pattern matching, CSS-selector DOM parsing, price normalization and threshold comparison. Background checks use the Chrome Alarms API.
  • Correct price on 20 of 20 benchmark pages, 8 of 8 normalization cases and 25 of 25 target-price events.
  • Rated 3.97 out of 5 by three IT experts (ISO/IEC 25010) and 72.5 on the System Usability Scale by 17 users, above the common average of 68.
  • My part: the research paper, including its figures and models, and organizing the questionnaire data. I took part in the ten Agile sprints and defended the thesis before a panel.
  • JavaScript
  • Chrome Extension API
  • IndexedDB
  • DOM parsing
